## Introduction

This repository is a running record of the Design and Analysis of Algorithms
Laboratory at IIIT Bhubaneswar. Every lab session gets its own folder, and each
folder holds the source files written for that session's problem set.

DAA is less about getting a program to run and more about showing how it
behaves as the input grows. So most programs here try to do two jobs at once:
solve the problem, and instrument themselves — counting comparisons, counting
moves, tabulating values across increasing `n` — and export that data as CSV
so the growth can be plotted rather than just asserted.

## About the Repository

- Written entirely in **C**, compiled with **GCC**.
- One directory per lab session (`WEEK 1`, `WEEK 2`, …), each containing the
  question paper alongside the solutions.
- File names describe the problem, not just the question number — e.g.
  `Q4 tower of hanoi.c` rather than `q4.c`.
- Programs that study growth write their measurements to a **CSV** file, which
  is then plotted and committed as an **SVG** next to it.
- Every program closes by printing its own time and space complexity, so the
  analysis travels with the code rather than living in a separate note.
- No external libraries — only the C standard library.

## Compilation and Execution

```bash
cd "WEEK 1"

# Programs that use log/pow/sqrt need the math library
gcc -Wall -Wextra Q1growth.c -o q1 -lm
./q1

# Others need no extra linkage on GCC
gcc -Wall -Wextra "Q4 tower of hanoi.c" -o q4
./q4
```

Recommended flags while working:

```bash
gcc -std=c11 -Wall -Wextra -O2 file.c -o out -lm
```

**On Windows** (MinGW-w64), replace `-o q1` with `-o q1.exe` and run `q1.exe`.

**Note on generated files.** Programs that write CSVs do so into the *current
working directory*. Running them from inside `WEEK 1` will overwrite the
committed copies — build and run from a scratch directory if you want to keep
those files untouched:

```bash
mkdir -p /tmp/daa && cd /tmp/daa
gcc -Wall -Wextra "$OLDPWD/WEEK 1/Q4 tower of hanoi.c" -o q4 && ./q4
```

## Repository Conventions

- One folder per lab session, named `WEEK <n>`, containing the question paper
  and every solution for that session.
- Sources are named `Q<number><short description>.c`.
- Every program prints its own time and space complexity before exiting.
- Generated CSVs keep the name of the analysis they describe, and their plots
  share that name with an `.svg` extension.
