# Coin Toss Simulation – DAA Lab (Week 1)

## Overview

This project simulates the tossing of two different coins using C:

- **Fair Coin** – Probability of Heads = **0.5**
- **Biased Coin** – Probability of Heads = **0.7**

The simulation performs **100,000 trials** and records the running probability of obtaining heads for both coins at regular intervals. The generated data is stored in a CSV file for visualization and analysis.

---

## Features

- Simulates a fair and a biased coin simultaneously
- Performs **100,000 coin tosses**
- Calculates the running probability of heads
- Records data after every **100 trials**
- Generates a **results.csv** file for plotting graphs
- Demonstrates the Law of Large Numbers through simulation

---

## Objective

The objective of this experiment is to compare how the observed probability of heads approaches the theoretical probability as the number of trials increases.

Expected probabilities:

- **Fair Coin:** 0.50
- **Biased Coin:** 0.70

---

## Methodology

1. Initialize the random number generator.
2. Simulate a fair coin toss using `rand() % 2`.
3. Simulate a biased coin toss using a random number between **0** and **1**.
4. Repeat the experiment for **100,000 trials**.
5. After every **100 trials**, calculate the running probabilities.
6. Store the results in **results.csv**.

The generated **results.csv** file can be imported into **Microsoft Excel** to create a line graph comparing:

- Running probability of the **Fair Coin**

As the number of trials increases, the probabilities converge towards **0.5** and **0.7**, respectively.

---

## Build and Run

Compile the program using GCC:

```bash
gcc coin_simulation.c -o simulation
```

Run:

```bash
./simulation
```

## Complexity Analysis

| Complexity | Value |
|------------|-------|
| Time Complexity | **O(n)** |
| Space Complexity | **O(1)** |

where **n = 100,000** trials.

---

## Observations

- The observed probability of the fair coin gradually approaches **0.5**.
- The observed probability of the biased coin gradually approaches **0.7**.
- Increasing the number of trials reduces random fluctuations.
- The experiment demonstrates the **Law of Large Numbers**, where experimental probabilities converge to theoretical probabilities over many trials.
