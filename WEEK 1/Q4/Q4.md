# Towers of Hanoi – DAA Lab (Week 1, Question 4)

## Overview

This project implements the **Tower of Hanoi** problem using recursion in C. It demonstrates the recursive solution, counts the number of moves required for different numbers of discs, and verifies the recurrence relation and its closed-form solution.

The program also exports the move count data to a CSV file for visualization in Microsoft Excel.

---

## Features

- Recursive implementation of the Tower of Hanoi algorithm
- Displays the complete move sequence for **4 discs**
- Counts the number of moves for **1 to 20 discs**
- Verifies the formula **2ⁿ − 1**
- Generates **hanoi_data.csv** for plotting graphs
- Demonstrates exponential time complexity

---

## Recurrence Relation

```
T(n) = 2T(n-1) + 1
T(0) = 0
```

### Closed Form

```
T(n) = 2ⁿ − 1
```

---

## Algorithm

1. Move **n − 1** discs from the source peg to the auxiliary peg.
2. Move the largest disc to the destination peg.
3. Move the **n − 1** discs from the auxiliary peg to the destination peg.
4. Repeat recursively until all discs are moved.

---

## Output

The program produces:

- Complete move sequence for **n = 4**
- Comparison of recursive move count and formula (**2ⁿ − 1**) for **n = 1 to 20**
- **hanoi_data.csv** containing:

| n | Moves |
|---|------:|
|1|1|
|2|3|
|3|7|
|...|...|
|20|1048575|

## Build and Run

Compile the program using GCC:

```bash
gcc Tower_of_Hanoi.c -o hanoi
```

Run:

```bash
./hanoi
```

---

## Time Complexity

- **Time Complexity:** `O(2^n)`
- **Space Complexity:** `O(n)` (recursive call stack)
