# DAA Lab-02: Merge Sort vs Modified Merge Sort

## Problem Statement

Implement and compare standard **2-way Merge Sort** with a modified **3-way Merge Sort**. In the modified version, the input array is divided into three parts, each part is recursively sorted, and the three sorted parts are combined using a three-way merge procedure.

The objective is to determine the worst-case time complexity of the modified algorithm and validate the theoretical result experimentally by measuring the execution time for increasing input sizes.

## Objectives

- Implement 2-way Merge Sort.
- Implement 3-way Merge Sort.
- Analyze the worst-case recurrence of both algorithms.
- Measure execution time for increasing values of `n`.
- Verify the order of growth experimentally.
- Store timing results in a CSV file.
- Plot the execution time of both algorithms.
