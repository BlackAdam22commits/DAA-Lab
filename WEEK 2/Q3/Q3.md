# DAA Lab-02: Merging k Sorted Arrays

## Problem Statement

Given `k` sorted arrays, each containing `n` elements, merge them into a single sorted array containing `kn` elements.

Two methods are implemented and compared:

- **Method 1:** Sequentially merge the arrays one at a time.
- **Method 2:** Divide the `k` arrays into pairs, merge each pair, and continue merging the resulting arrays until one sorted array remains.

The programs validate both methods experimentally and analyze their running time as a function of `k` and `n`.

## Objectives

- Implement a merge procedure for two sorted arrays.
- Implement sequential merging of `k` sorted arrays.
- Implement pairwise merging of `k` sorted arrays.
- Compare the running time of both methods.
- Validate the correctness of the resulting sorted arrays.
- Analyze the worst-case time complexity with respect to `k` and `n`.
